# proposals/

This folder holds experimental feature design write-ups — ideas that aren't yet part of the active Experimental section in `docs/formulas/`.

Use it to sketch out a feature before committing to building it: what it does, how it might work, open questions. Once a proposal is ready to build, move it into the Experimental section of the relevant `docs/formulas/*.md` file and follow the version-management workflow from there.

**Suggested naming:** `[feature_name]_idea.md`
