# sample-data/

This folder holds the source data your AppSheet project is built from — CSV exports from Google Sheets, sample datasets, or any reference data used while designing tables, formulas, or views.

It can be anything: a full sheet export, a single tab, or a trimmed-down sample used for testing. There's no required format or naming convention — use whatever helps you (or an AI assistant) understand the shape of the data before building the app around it.

**Suggested naming:** `[Sheet Name]_[Tab Name].csv`
